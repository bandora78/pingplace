# PingPlace Product DNA

## Vision
Tell PingPlace once. Remember it when it matters.

Traditional reminders ask: “When should I remind you?”
PingPlace asks: “Where should I remind you?”

## Core model
Every reminder combines:
- WHAT — the task
- WHERE — the relevant place
- CONDITION — arrival or departure

## Principles
1. Location first.
2. Natural-language creation; target <= 5 seconds for an existing place.
3. Context over time.
4. Places become lists.
5. Battery friendly; no permanent GPS tracking.
6. Privacy first; no passive location history.
7. Quiet by design; group reminders by place.
8. Reliability is more important than feature count.

## Product North Star
“I don’t need to remember this anymore. PingPlace will.”

## Platform strategy
Android-first field testing with Flutter architecture designed for later iOS support.
